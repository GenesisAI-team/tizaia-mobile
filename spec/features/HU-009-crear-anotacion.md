# HU-009 — Crear anotación

Nueva anotación precarga alumno desde contexto o permite seleccionarlo, permite tipos Conductas contrarias, Conductas agravantes y Refuerzo positivo, y captura contenido. Guardar persiste alumno, tipo, contenido y fecha/hora, muestra “Anotación Guardada” y vuelve al origen. RF-NOTE-007..010, DAT-NOTE-001, BR-ANOT-001. Validaciones y longitud: abiertas.
